# Color Picker Chrome Extension

A lightweight Chrome extension designed to help users pick colors from webpages and quickly copy color values for design and development workflows.

> Portfolio project showcasing browser extension development and practical frontend tooling.

## Overview

The Color Picker extension makes it easier to identify and reuse colors while browsing websites. It is intended to support designers, developers, and anyone working with web interfaces.

## Features

- Pick colors from webpages.
- Copy color values for reuse in designs and code.
- Simplify everyday color selection workflows.
- Lightweight browser-extension interface.

## Technologies

- JavaScript
- HTML
- CSS
- Chrome Extension APIs

## Project Status

This repository is a portfolio overview. The feature descriptions represent the intended functionality; implementation details may vary depending on the version of the extension.

## Purpose

Built as a practical browser-tool project to demonstrate frontend development skills and an interest in useful developer utilities.
